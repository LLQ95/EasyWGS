# 两条并行分析策略

easyWGS 提供两条从同一批清洗后 reads 出发、但回答不同问题的并行主路线：一条基于组装拼接（de novo 重建每个基因组），另一条基于参考基因组比对（把 reads 直接比对到一株完整参考基因组，生成 BAM，再用 bcftools 检测变异）。两条路线汇入同一套分型、汇总与可视化层，既可以单独运行，也可以同时运行以便相互印证结论。

## 组装路线（de novo）

`run_assembly.sh` 驱动的路线依次为质控（模块 01）、reads 去污染（02）、按平台组装（03）、组装质控与去污染门控（04）、注释（05）、分型（06）、耐药/毒力/可移动元件筛查（07）、泛基因组聚类（08）、基于组装结果的核心 SNP 系统发育（09）、分子定年（10）、汇总报告（99）与可视化（11）。后续所有步骤都消费统一的 `03_assembly/genomes/{id}.fasta`。

由于每个基因组不依赖参考而独立重建，组装路线能够恢复分离株的全部基因内容，包括所选参考基因组不携带的基因，即附属基因、质粒、前噬菌体、整合子、基因组岛以及大片段插入缺失。因此它天然适合注释、泛基因组研究、覆盖整个物种或系统发育差异较大的集合、质粒与可移动元件分析，以及没有单一近缘完整参考基因组的项目。

## 参考比对路线（reads mapping）

`run_mapping.sh` 驱动的路线依次为质控与去污染（01 至 02）、模块 12 的参考比对（Illumina 用 BWA-MEM，ONT/PacBio 用 minimap2，随后用 samtools 排序建索引并统计覆盖度）、模块 12.2 用 bcftools 联合检测变异，产出原始、过滤与双等位 VCF 以及基因型矩阵，最后进入模块 13 的微生物 GWAS。如 `run_mapping.sh` 顶部所示，也可以从双等位 VCF 构建参考路线的 SNP 树并交给模块 10 做分子定年。

所有基因组都被投影到同一套参考坐标上，因此大量分离株之间的位点可以直接比较，在中等测序深度下仍有较高的变异检出灵敏度，单基因组计算开销也较低。这条路线适合克隆性暴发的溯源与监测、拥有高质量近缘参考（例如一株完整的暴发源菌株）的集合、快速统一的 SNP/indel 表，以及 de novo 组装无法提供的等位频率或低深度分析。

## 如何选择

| 维度 | 组装路线 `run_assembly.sh` | 参考比对路线 `run_mapping.sh` |
| --- | --- | --- |
| 近缘完整参考 | 不需要 | 强烈建议有 |
| 主要产物 | contig、基因、泛基因组 | 统一坐标下的 BAM、VCF、SNP 矩阵 |
| 附属基因/质粒/可移动元件/基因获得缺失 | 直接恢复 | 仅覆盖能比对到参考的部分 |
| 中等深度下 SNP/indel 灵敏度 | 受可组装性限制 | 高，带逐位点深度与基因型质量 |
| 跨样本统一坐标 | 需经泛基因组/比对后才有 | 天然具备 |
| 超大克隆集合的速度与成本 | 较高 | 较低 |
| 暴发/传播聚类 | 支持（基于组装的核心 SNP） | 有近缘参考时最快 |
| 系统发育差异大或新谱系集合 | 更合适 | 会受参考选择偏倚影响 |
| 结构内容与基因组大小 | 可恢复 | 不能直接得到 |
| GWAS 特征层 | 基因有无（Scoary、pyseer 基因层） | SNP（PLINK、pyseer SNP 层） |

在实际工作中两条路线互补而非互斥。对于有完整源菌株参考的克隆性暴发，比对路线能最快、最灵敏地给出 SNP 距离，而组装路线用于确认基因内容、耐药决定子与质粒结构。对于覆盖整个物种或尚不了解的集合，应以组装路线为主干，在有代表性参考时再补充比对路线。运行 `run_all.sh` 会同时执行两条路线；当项目目标单一时，只运行其中一个驱动脚本即可。
