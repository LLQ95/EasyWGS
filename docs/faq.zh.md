# 常见问题

## 组装污染率略高于 1% 怎么办

先看污染来自哪里：用 FCS-GX 或 BlobToolKit 定位外源 contig，移除后回到 04 重新
评估；若污染分散在目标 contig 内部、无法按 contig 干净切除，回到 02 加强 reads
去污染后重组装，不要带着内部嵌合继续分型。

## 只有三代数据，结果可靠吗

ONT 高质量芯片加上 Flye、有限轮 Racon、Medaka 抛光后，结构与成环可靠，但碱基级
精度仍建议用短读 Pilon 回填；没有短读时，耐药基因、点突变等单碱基层面的结论要
用另一工具复核。PacBio HiFi 的单读准确率高，纯 HiFi 组装通常不需要过多抛光。

## Racon 或 Medaka 要跑几轮

Racon 控制在两到三轮，更多轮会过校正、抹掉真实变异；Medaka 一轮即可，关键是模型
与芯片、碱基识别版本匹配。盲目叠加抛光轮数不是提高质量的可靠办法。

## 混合组装反而更差是什么原因

混合组装会同时放大短读里的污染：长读把杂菌也拼成完整片段。因此混合前必须先让
短读通过 02 去污染，并在 04 用 CheckM2/GUNC 复核。

## cgMLST 和核心 SNP 树结果不一致

二者尺度不同，近缘暴发看 cgMLST 等位差异，跨克隆群看 SNP 树。若同一传播簇内
出现明显矛盾，先核对参考选择、重组去除和样本污染，再讨论生物学差异。

## FCS-GX 数据库太大跑不动

本地不具备约 512 GB 内存条件时，保留 CheckM2 与 GUNC，把组装上传 usegalaxy.org
在线运行 FCS-GX，再把净化后的 fasta 放回 04 目录继续下游即可。

## 如何复现旧项目结果

记录各环境的软件版本（`conda list --explicit`）、数据库版本与样本表；同一份样本表
加同一版本数据库，配合 run_all 的步骤号即可从任意阶段复现。
